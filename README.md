# Homebrew Tap: SDLC Wizard

Homebrew tap for [agentic-sdlc-wizard](https://github.com/BaseInfinity/agentic-ai-sdlc-wizard).

## Install

```bash
brew install BaseInfinity/sdlc-wizard/sdlc-wizard
```

## Usage

```bash
sdlc-wizard init        # Install wizard to current project
sdlc-wizard check       # Check installation health
```

## Update

```bash
brew upgrade sdlc-wizard
```
